# Seattle_WLafayette Percipitation Comparison

> Review the difference between the Precipitation levels of Seattle and West Lafayette, Indiana.

---

## Project Overview
This project intended to compare the percipitation levels between Seattle, Washington and West Lafayette, Indiana. Data is pulled from NOAA website and finds that Seattle has a higher percipitation level on average as well as a higher percentage of days of percipitation, leading us to believe that Seattle is the rainier city.

- **Objective:** Determine which city is rainier, Seattle or West Lafayette.
- **Domain:** Weather

## Data

- **Source:** NOAA Site - https://www.ncei.noaa.gov/cdo-web/search
- **Description:** Datasets from NOAA site in Seattle and West Lafayette contain information on daily Precipitation, the stations being used, and the dates of precipitation.

---

## Analysis

Run the file "Weather_Seattle_WLafayette" first and then "Exploratory Weather Analysis Seattle W Lafayette". The first does the majority of the data cleaning whereas the analysis is primarily run in the second set of code.

---

## Results

After conducting the analysis of datasets, it was determined that Seattle is a rainier city than West Lafayette. This can be seen in both the fact that there are more days with percipitation, but also more net percipitation across the year.
